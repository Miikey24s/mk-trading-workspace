## Review findings

1. The current visual language is coherent and readable for the represented
   MT5 views: flat-first dark shell, explicit state labels, restrained borders,
   and a visible simulation/read-only lock. The 360px Learn fixture remains
   scannable by stacking course, reader, and glossary panes.
2. The shared release is intentionally small. It proves semantic tokens plus
   one neutral/primary native-button contract in both consumers. It does not
   prove a reusable loading/empty/error/stale pattern or a complete VI
   workspace theme.
3. Focus styling is guaranteed for `.ui-button`; consumer-owned controls
   still depend on each product's local styles. Expanding that contract would
   be an additive shared API and needs a new representative fixture before
   promotion.
4. VI `ui/project-ui.json` remains `partial-migration` and pins the shared
   control only for `header.raw-json-control`. That is correct for the current
   bounded M4 scope; do not silently broaden it while M5 catalog/review
   contracts are still pending.
5. No Figma/Make round-trip or whole-app/global visual approval is claimed.
   Existing M2/M4 closeout remains scoped and authoritative.
6. The VI quality-profile choices now use native radio semantics and visible
   keyboard focus in nested-repo commit `89e9d54`; this remains project-local
   and does not widen the shared button contract. The same checkpoint removes
   invented telemetry/ETA values from the audited VI cards and adds dialog
   semantics/Escape handling to the two inspected modals. Remaining keyboard
   and contrast gaps are listed below as backlog, not acceptance claims.
