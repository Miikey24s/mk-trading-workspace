## Hành vi đã thay đổi

P1 hiện có một app Flask read-only riêng trên `p1_app.py`, không import `app.py` hoặc `mt5_data.py`, với UI Evidence Explorer riêng. UI liệt kê run, mở provenance/assumptions, official metrics, equity curve, ledger và drill-down một trade qua endpoint inspector; export JSON/CSV lấy từ cùng canonical read model.

P1 không có route execution. SQLite reader mở `mode=ro`; runtime DB path có thể truyền explicit bằng `EVIDENCE_DB_PATH`.

## Data/state flow

`SQLite replay session -> EvidenceStore -> normalized ledger -> metrics-v1 -> P1 API -> Evidence UI/export`

Frontend không tự tính win rate, profit factor, expectancy, realized R hoặc drawdown. Canvas chỉ vẽ các equity sample do Python core trả về.

Legacy field thiếu provenance/cost/risk/version vẫn là `null` và được UI render thành `unknown`. `comparison.ready=false` cho các run legacy chưa đủ dữ liệu so sánh.

## Safety và error states

- Import/start P1 không import legacy MT5 app hoặc mở execution route.
- Artifact schema không đúng trả `SCHEMA_UNSUPPORTED`.
- SQLite summary không khớp normalized ledger trả `RECONCILIATION_MISMATCH`.
- Payload JSON hỏng trả `ARTIFACT_INVALID`.
- Missing/offline DB trả `READ_FAILURE`, không tự tạo file.
- UI render dữ liệu artifact bằng DOM `textContent`, không dùng `innerHTML` cho field động.
- Shell gửi CSP, `no-store` và `nosniff`; CSV neutralize string bắt đầu bằng `=`, `+`, `-`, `@`.
- CSV export mang cùng provenance/read-model chính đang hiển thị: identity, data, assumptions, reproduce, comparison, metrics và ledger.
