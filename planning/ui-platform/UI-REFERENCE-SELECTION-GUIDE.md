# UI reference selection guide

Purpose: help the user select inspiration without requiring design vocabulary.

## Simple glossary

| Term | Simple meaning |
|---|---|
| Visual hierarchy | Mắt nhìn cái gì trước, cái gì sau |
| Density | Màn hình chứa nhiều hay ít thông tin |
| Navigation | Cách đi giữa các khu/màn hình |
| Context panel | Khung phụ hiện thông tin của thứ đang chọn |
| Data storytelling | Sắp số/chart để người xem hiểu câu chuyện của dữ liệu |
| Design token | Tên chuẩn cho màu/khoảng cách/font/trạng thái để đổi đồng bộ |
| Component | Mảnh UI dùng lại như nút, bảng, tab, metric |
| Pattern | Cách ghép nhiều component cho một việc lặp lại |
| Theme | Cùng cấu trúc nhưng thay diện mạo như màu/font/radius |
| Visual QA | Kiểm giao diện bằng render/screenshot để phát hiện lệch/xấu/lỗi |

## Selection method

For each UI part, compare several references and choose one of:

- `TAKE`: thích gần như nguyên ý tưởng;
- `ADAPT`: thích ý tưởng nhưng phải đổi cho app mình;
- `REJECT`: không hợp;
- `UNSURE`: cần xem thêm hướng.

Record why. "Looks nice" is allowed, but add one practical reason when possible.

## Parts to select separately

1. Main navigation: sidebar/topbar/workspace tabs.
2. Information density: spacious/balanced/dense.
3. Typography: calm/readable vs compact/terminal-like.
4. KPI/metric presentation.
5. Main chart workspace.
6. Replay controls.
7. Tables and row inspection.
8. Right-side context/watchlist/details panel.
9. Research/form flow.
10. Analytics story: summary → risk → evidence → trades.
11. Alerts/status/missing-data presentation.
12. Dark/light behavior.
13. Window/layout persistence.
14. Mobile/narrow-width fallback if required.
15. Motion/hover/selection feedback.

## Reference rule

Do not attach a reference image to an AI generator without stating exactly which parts are inspiration. Otherwise the generator may copy unwanted layout/color decisions along with the desired pattern.
