# Figma adapter

Purpose: precise design-system authoring, component/variable management, design review, and round-trip design/code workflows.

Preferred uses:

- refine and systemize an approved visual direction;
- maintain native Figma components/variables when Figma is part of the workflow;
- use Figma MCP so coding agents can work from approved design context;
- use code-to-canvas to review implemented UI as editable design layers when appropriate.

Figma is an adapter/authoring environment. Portable semantic contracts and token data remain outside any single vendor tool.
